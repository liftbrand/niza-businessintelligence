# NIZA Air · Jets en Costa Rica

Landing público con la inteligencia de aviación privada de NIZA Air: aterrizajes de jets ejecutivos en Liberia (LIR), Juan Santamaría (SJO) y Pavas (SYQ) entre octubre 2024 y octubre 2026.

- Un solo archivo estático: `index.html` (logo, fotografía y datos agregados incluidos).
- Fuente de datos: Flightradar24 API (resúmenes de vuelo). Solo cifras agregadas; no incluye matrículas.
- Despliegue: Vercel, sin build. Cada push a `main` publica en producción.
